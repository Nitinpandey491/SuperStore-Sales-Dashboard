# 📊 SuperStore Sales Dashboard & Forecast

An interactive **Power BI Dashboard** built using the SuperStore dataset to analyze sales, profit, orders, regions, products, shipping performance, and future sales trends.

---

# 🌟 Overview

The dashboard provides a clear view of business performance through interactive visualizations and KPIs.

It includes:

- 💰 Sales & Profit Analysis
- 🛒 Orders & Customer Segments
- 🌎 Regional & State-wise Analysis
- 📦 Category & Sub-Category Analysis
- 🚚 Shipping Performance
- 📅 Monthly Sales & Profit Trends
- 🔮 15-Day Sales Forecast

---

# 🛠️ Tech Stack

| Category | Tools |
|----------|-------|
| BI Tool | Power BI |
